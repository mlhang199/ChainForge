# Week 12 MEV 案例分析：三明治攻击实例

> 分析平台：eigenphi.io / etherscan.io

---

## 攻击概述

**攻击类型**：Sandwich Attack（三明治攻击）

三明治攻击是 DeFi 中对普通用户伤害最大的 MEV 形式。攻击者监控 mempool，在目标交易前后各插入一笔交易，通过价格滑点获利。

### 攻击流程

```
1. 攻击者在 mempool 中发现受害者的大额 swap 交易
2. Front-run：攻击者以更高 gas 提交买入交易，推高代币价格
3. Victim：受害者的交易以更差价格执行（滑点被放大）
4. Back-run：攻击者立即卖出代币，收割价差利润
```

## 真实案例分析（基于典型三明治模式）

### 交易结构

| 角色 | 交易类型 | 说明 |
|------|----------|------|
| Front-run Tx | 买入代币 X | 攻击者先买入，推高价格 |
| Victim Tx | 买入代币 X | 受害者以更差价格成交 |
| Back-run Tx | 卖出代币 X | 攻击者卖出获利 |

### 关键数据（典型值）

| 指标 | 值 |
|------|------|
| 受害代币对 | WETH/USDC |
| 受害者滑点设置 | 3%（300 bps） |
| 受害者输入量 | ~10 ETH |
| 攻击者利润 | ~0.05-0.3 ETH（取决于流动性深度） |
| Front-run Gas 加价 | 10-50% 高于正常 gas |

### 为什么攻击成功

1. **滑点设置过宽**：3% 滑点给攻击者留下了利润空间
2. **交易金额大**：大额交易的价格冲击更显著
3. **流动性不够深**：池子深度不足，价格更容易被推动
4. **公开 Mempool**：交易在确认前对所有人可见

## 防御策略

### 1. 收紧滑点（最简单）

| 操作类型 | 推荐滑点 |
|----------|----------|
| 稳定币互换 | 0.1%-0.5% |
| 主流代币 | 0.5%-1% |
| 小市值代币 | 1%-3% |

### 2. 使用 Flashbots Protect RPC

```javascript
const provider = new ethers.JsonRpcProvider("https://rpc.flashbots.net");
```

Flashbots Protect 将交易直接发送给区块构建者，不进入公开 mempool。

### 3. Commit-Reveal 模式

适用于拍卖等场景，先提交哈希，后揭示出价，防止出价被 front-run。

### 4. 私有交易服务

| 服务 | RPC | 特点 |
|------|-----|------|
| Flashbots Protect | `https://rpc.flashbots.net` | 免费，最广泛使用 |
| MEV Blocker | `https://rpc.mevblocker.io` | 回扣机制 |
| BloxRoute | 需要注册 | BDN 加速 |

## 关键教训

1. **永远不要设置过宽的滑点** — 超过 1% 的滑点对大额交易就是攻击邀请
2. **使用私有交易渠道** — 不进入公开 mempool 就无法被 front-run
3. **拆分大额交易** — 多笔小额交易的 MEV 暴露低于一笔大额交易
4. **理解 AMM 机制** — x*y=k 的价格冲击是可预测的，攻击者也在计算
5. **监控链上活动** — 如果发现异常 gas 竞价，可能是 MEV 搜索者在活动
